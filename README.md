# Portfólio Web - Ronald Jones

Projeto desenvolvido na disciplina de Front-End e Back-End para Web. Reúne uma landing page profissional responsiva, um currículo online e uma aplicação de perfil feita com JavaScript.

## Páginas

| Arquivo | Descrição |
|---|---|
| `index.html` | Landing page com Bootstrap 5: navbar, hero, sobre mim, habilidades, projetos, formulário de contato e rodapé. |
| `curriculo.html` | Currículo online com menu de navegação, tabela de formação e competências. |
| `perfil.html` | Currículo Web Inteligente: formulário que salva o perfil no navegador, alterna entre tema claro e escuro e registra a última visita. |

## Tecnologias utilizadas

- **HTML5**: estrutura semântica das páginas
- **CSS3**: Flexbox, variáveis CSS, media queries e animações
- **JavaScript**: manipulação do DOM, eventos e `localStorage`
- **Bootstrap 5.3**: grid, navbar, cards, formulários e classes utilitárias
- **Git e GitHub**: versionamento e publicação do projeto

## Como executar

1. Baixe o projeto ou clone o repositório:

   ```bash
   git clone https://github.com/rjonees/portfolio-web.git
   ```

2. Abra o arquivo `index.html` no navegador.

> O Bootstrap é carregado por CDN, portanto é necessário ter conexão com a internet.
